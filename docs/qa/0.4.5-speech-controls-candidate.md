# VoiceMatrix 0.4.5 candidate — speech controls and suggestions

This is a verified native candidate, not a published update. The public release and installation feeds remain 0.4.4.

## Behavior

The character speech screen no longer rejects text at 500 characters, and the planner no longer rejects at 5,000 UTF-8 bytes. It keeps complete words and the existing 22-second inference budget. A job is bounded to approximately 30 minutes of predicted/raw speech before speed changes; over-budget work fails clearly rather than dropping words. Raw chunks are written incrementally, and cancellation removes incomplete output.

Speed (0.5–2x), pitch (-12–12 semitones), volume (25–100%) and inter-part pauses (0–1 second) are available in Speech controls, with Reset and a summary of the settings used for each output. Speed, pitch and volume are rendered offline into the saved/shared WAV. References and existing saved recordings are unchanged. Extreme pitch changes can change perceived resemblance.

The suggestion screen retains a local draft and requires acknowledgement that submissions are public. It opens a GitHub issue draft containing exactly the user-entered title/body with a VoiceMatrix title prefix. Opening transmits that text in the browser URL; publication requires GitHub sign-in and a separate Submit action. No credential, speech text, audio, profile identifiers, logs or device metadata is attached automatically. Do not enter private information.

A daily task around 08:00 UTC is configured and enabled to review open issues authored by R347H4CK3R with titles beginning exactly [VoiceMatrix suggestion]. Its recorded configuration was read back, and the GitHub issues endpoint was successfully read with no matching requests. No scheduled execution result has yet been verified. It can investigate and test feasible requests, report blockers, and avoid duplicate work; automatic fulfillment or publication is not guaranteed. Other issue authors are not treated as the owner's authorization. No private suggestion inbox is claimed.
