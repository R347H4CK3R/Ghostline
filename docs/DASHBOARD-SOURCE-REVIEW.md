# Dashboard to source review

The progress dashboard can link an eligible queued video directly to its authenticated companion review page, preselecting the canonical video ID. It reads only a secret-free LaptopSettings.json in the companion root: HTTPS .ts.net root URL plus authentication=tailscale-same-account. Missing/malformed/credential-bearing/non-Tailscale settings produce no review link and do not hide queue progress. Hostnames are ASCII DNS-validated and URLs reconstructed from parsed hostname and numeric port; backslash/control-character parser ambiguities are rejected.

Waiting/awaiting-preparation/paused entries show Review source only when there is no saved recipe or specification. Existing prepared work shows Review saved; terminal/active entries require a separate recovery/replacement workflow. Clicking does not approve a source, infer identity, create a model or bypass the form's explicit reviewed-use/label gates. Existing authentication and request nonce are unchanged. GET /review accepts only an optional single canonical video query; arbitrary query/path values are rejected. No link, queue entry or voice is deleted.
